# BitcoinBruteForceTest

پروژه مستقل اندروید برای شبیه‌سازی آموزشی محلی.

## ساختار و امکانات
- رابط کاربری XML
- اجرای شبیه‌سازی با یک دکمه
- شناسه‌های تصادفی ساختگی و شمارنده آزمایش
- نمایش و پاک‌کردن نتایج
- بدون نیاز به اینترنت یا اتصال به کیف‌پول

## محدودیت
این نسخه کلید خصوصی، عبارت بازیابی یا آدرس واقعی بیت‌کوین تولید یا حدس نمی‌زند و موجودی شبکه اصلی را جست‌وجو نمی‌کند؛ خروجی‌ها صرفاً داده ساختگی هستند.

## ساخت APK
با push روی شاخه main یا اجرای دستی workflow با نام Build BitcoinBruteForceTest APK، فایل APK در بخش Artifacts قرار می‌گیرد.
